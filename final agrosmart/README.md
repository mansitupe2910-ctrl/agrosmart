# AgroSmart - शेतकरी सेवा व शासकीय योजना पोर्टल

महाराष्ट्रातील शेतकरी बांधवांसाठी पशुवैद्यकीय अधिकारी संपर्क, माती परीक्षण प्रयोगशाळा, सेतू केंद्र आणि सर्व शासकीय योजनांची संपूर्ण माहिती देणारे सोपे वेब पोर्टल.

## 🚀 फीचर्स (Features)
- **१. पशुवैद्यकीय डॉक्टर दालन:** पशुवैद्यकीय अधिकारी, दवाखान्याचा प्रकार व थेट कॉल बटण
- **२. माती परीक्षण केंद्र:** शासकीय व केव्हीके प्रयोगशाळा, तपासणी शुल्क व नमुना काढण्याच्या ३ सोप्या पायऱ्या
- **३. सेतू व मदत केंद्र:** आपले सरकार व सेतू केंद्रे आणि प्रमुख मोफत शासकीय हेल्पलाइन (1800-180-1551, 1962, 14447)
- **४. शासकीय योजना:** नमो शेतकरी, १ रुपयात पीक विमा, सोलर पंप, शेततळे, ट्रॅक्टर अनुदान इत्यादींची सविस्तर माहिती
- **जिल्हा निवडक:** महाराष्ट्रातील सर्व जिल्ह्यांसाठी सुलभ फिल्टर

## 🛠️ तंत्रज्ञान (Tech Stack)
- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (Icons)

## 💻 लोकल कम्प्युटरवर चालवण्यासाठी (Local Development)
```bash
# रिपॉझिटरी क्लोन करा
git clone https://github.com/<YOUR-USERNAME>/agrosmart.git
cd agrosmart

# पॅकेज इन्स्टॉल करा
npm install

# लोकल सर्व्हर सुरू करा
npm run dev
```

## 🌐 Vercel वर डिप्लॉय कसे करावे (Deploy on Vercel)
1. **[Vercel.com](https://vercel.com)** वर लॉगिन करा.
2. **"Add New..."** वर क्लिक करून **"Project"** निवडा.
3. तुमच्या GitHub मधील **`agrosmart`** रिपॉझिटरी निवडा आणि **Import** वर क्लिक करा.
4. Framework Preset: **`Vite`** (आपोआप निवडले जाईल).
5. **"Deploy"** बटणावर क्लिक करा.
6. तुमचे ॲप १ मिनिटात लाइव्ह होईल!
